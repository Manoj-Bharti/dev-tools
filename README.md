# DevToolkit

Privacy-first developer utilities. All tools run in the browser (client-side).

Quickstart

1. Install dependencies

```bash
pnpm install
# or npm install
```

2. Run dev server

```bash
pnpm dev
```

Project structure

- `src/app` - Next.js app routes (App Router)
- `src/components` - shared UI components
- `src/lib` - utilities and constants

Deployment

1. Create a GitHub repo and push.
2. Connect repository to Vercel and set framework to Next.js.

Privacy

All processing happens in the browser. No analytics are included by default.
