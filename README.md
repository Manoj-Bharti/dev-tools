# DevToolkit

Privacy-first developer utilities. All tools run in the browser (client-side).

Quickstart

1. Install dependencies

```bash
pnpm install
# or npm install
```

2. Run dev server

```bash
pnpm dev
```

Project structure

- `src/app` - Next.js app routes (App Router)
- `src/components` - shared UI components
- `src/lib` - utilities and constants

Deployment

1. Create a GitHub repo and push.
2. Connect repository to Vercel and set framework to Next.js.

Privacy

🔒 **Your privacy matters.** All tools run entirely in your browser:
- No data is sent to our servers
- No cookies or tracking
- No analytics (currently)
- No user accounts
- Open source - verify for yourself

Read our full [Privacy Policy](https://common-dev-tools.netlify.app/privacy).
